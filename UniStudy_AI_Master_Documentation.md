**1.1 Vision**
--------------

UniStudy AI is a full-stack web and mobile platform purpose-built for university students in Ghana and across Africa. It transforms how students engage with lecture content by making AI explanation, smart practice, past-paper revision, and study community features available in one place — with no subscription barrier for core features and a clear paid tier for power users.

**1.2 Target Users**
--------------------

*   Primary: University students (100 to 400-level) in Ghana, Nigeria, Kenya, South Africa
*   Secondary: Lecturers who want to share slides and monitor student engagement
*   Tertiary: University institutions seeking a white-labelled study platform

**1.3 Core Value Proposition**
------------------------------

*   Upload any lecture PDF or PPTX — AI explains every slide instantly
*   Automatic flashcards, quizzes, and summaries from your own slides
*   Full past-paper revision suite with AI grading and weakness drilling
*   Social study features: groups, leaderboards, flashcard battles
*   100% free-tier infrastructure — zero fixed server cost at launch

### **Masterpiece Prompt Logic**

The explanation prompt has two modes — automatically detected:

*   CALCULATION MODE: triggered when slide contains equations, formulas, or numerical problems. Uses WHY-then-HOW structure. Works every step. Anti-essay guard: 'Do NOT write prose where a worked example belongs.'
*   CONCEPTUAL MODE: triggered for theory, definitions, and diagrams. Uses analogy-first approach calibrated to the student's learning style.

If it contains equations, formulas, or calculations → CALCULATION MODE.<br>If it contains concepts, definitions, or diagrams → CONCEPTUAL MODE.<br>CALCULATION MODE RULES:<br>- Start with WHY this type of problem matters (1 sentence)<br>- Work through every step with full working shown<br>- Each step: state what you are doing BEFORE you do it<br>- Anti-essay guard: do NOT write a paragraph where a worked example belongs<br>- End with the pattern: 'Whenever you see [X], always [Y]'<br>CONCEPTUAL MODE RULES:<br>- Start with a real-world analogy the student will recognise<br>- Then give the academic definition<br>- Explain WHY this concept exists (problem it solves)<br>- Give one concrete example<br>- End with exam-likely phrasing of this concept<br>Slide content: ${slide_text}<br>Respond in Markdown with clear headings.
