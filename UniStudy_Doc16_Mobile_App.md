**MOBILE APP OVERVIEW**  
The UniStudy AI mobile app is built with Expo (managed workflow) and shares the same Supabase backend, API routes, and AI providers as the web app. No separate backend is needed. The mobile app adds device-native features: camera for slide capture, push notifications, offline flashcards, and a lock screen widget.
